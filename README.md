 ## **workers-data-postgres-analysis**
 ### Workers Dataset Analysis — PostgreSQL &amp; Python. 
 This repository contains an end-to-end analysis of a workers/income dataset (based on the classic Workers_data csv), covering data cleaning, exploratory data analysis, and statistical querying. 
My goal for this repository was to make it a testament of my learning phase with postgresql and integration with python analysis as well as visualization using the matplotlib python library and the the y_data profiling report.
